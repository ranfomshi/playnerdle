WATCH. HOLD. RECOGNISE.

A workout for visual memory.

Each level adds another colour until the sequence reaches eight. After the final flash, choose the exact order from four options. Some choices use the same colours in the wrong order; others change only one colour. Three mistakes end the run.

About the game

How to play Seequence

Memorise a colour sequence, then reproduce the exact pattern after it disappears.

Format
Progressive memory streak
Typical round
About 2–6 minutes
Cost
Free, with no download required

The rules

Watch the sequence without making choices, hold the order in memory, and reproduce it only when playback ends. Longer patterns follow successful answers.

What makes it different

The interface separates watching from answering, so the challenge measures the sequence you retained rather than your ability to copy it live.
