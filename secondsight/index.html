The rules

Study one colour, hold it through a blank interval, then study a second. Decide whether the second became lighter, darker, more vivid, more muted, redder, greener, yellower or bluer.

What makes it different

The colours never appear together until after the answer. Each round changes exactly one perceptual dimension, turning colour memory into clear, learnable feedback.

What does this colour perception test measure?

Second Sight challenges your ability to notice the direction of a colour change from memory. It separates changes in brightness, saturation and hue so the feedback remains understandable.

Is Second Sight a medical vision test?

No. It is a perceptual memory game rather than a diagnostic assessment. Display settings, ambient light and individual screens can all change how the colours appear.
