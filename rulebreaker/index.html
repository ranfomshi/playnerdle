Decoder's notebook

How to find your first foothold.

01

Question the spaces

Word lengths survive most rules, so A, I, THE and AND are useful anchors. If none fit, test whether the breaks themselves have moved.

02

Fix shape before letters

If letters look scrambled inside otherwise believable word lengths, try reversals, rotations or neighbour swaps before alphabet shifts.

03

Change one thing

Add or tune one module at a time. The live output tells you whether that single decision revealed more language.

04

Follow repeated patterns

Repeated ciphertext shapes usually remain related. If the same cluster appears twice, expect the decoded fragment to repeat too.

05

Reorder promising rules

A useful rule in the wrong position can produce noise. Move it earlier or later before discarding it.

06

Read the signal relatively

The meter is most useful as a compass: keep changes that strengthen it, but trust recognisable language over tiny score movements.
