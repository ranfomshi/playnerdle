Trig Trek

Solve right-triangle challenges using trigonometry. Accuracy + speed = leaderboard-worthy runs.

How to play

  1. Read the triangle problem (you get an angle and one side length).
  2. Work out the missing side using sin, cos, or tan.
  3. Type your answer and press Submit before the timer ends.

Hint: SOH-CAH-TOA → sin(θ)=opp/hyp, cos(θ)=adj/hyp, tan(θ)=opp/adj.
